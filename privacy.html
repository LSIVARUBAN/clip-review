What is collected

When the owner connects their TikTok account, TikTok returns an access token and basic profile information (user.info.basic: an account identifier, display name and avatar). Clip Review uses these only to confirm which account is connected and to upload videos to that account's drafts (video.upload).

When the owner connects their Instagram professional account, Meta provides an access token and basic account information (instagram_business_basic: account ID and username). Clip Review uses these only to publish Reels the owner has approved to that same account (instagram_business_content_publish).

Where it is kept

The token is stored only on the owner's own computer, in a local file readable by the owner's user account. There is no server, database or cloud service run by Clip Review, and no analytics or tracking.

Sharing

Nothing is sold or shared with anyone. Data goes only to TikTok or Meta, through their official APIs, when a video is uploaded.

Other people

Clip Review does not collect information about other TikTok or Instagram users or viewers.

Removing data

The owner can disconnect at any time in TikTok's settings (Security → Manage app permissions) or in Instagram's settings (Website permissions → Apps and websites), and by deleting the local token file. Deleting the tool removes everything it stored. See data deletion.
